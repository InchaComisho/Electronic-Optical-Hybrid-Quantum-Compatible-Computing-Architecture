## 概要

このリポジトリは、**電子・光ハイブリッド量子互換コンピューティング構想**を提案するものです。

これは、従来の電子回路が得意とする制御、タイミング、記憶、誤り補正、校正、システム管理と、光システムが持つ多値・並列・高次元状態表現の可能性を組み合わせる、階層型の概念アーキテクチャです。

目的は、完成済みの量子コンピューターを主張することではありません。むしろ、近未来の決定論的な電子・光ハイブリッド計算と、長期的な光量子・qudit互換拡張をつなぐ橋渡し構造を定義することです。

電子システムは、信頼性の高い論理、記憶、順序制御、フィードバック、集積化に強みがあります。一方で、光システムは、高帯域伝送、並列状態表現、多値符号化、空間パターン処理、将来的な光量子状態処理において可能性を持ちます。

このリポジトリは、既存の **Optical Bead Computing / OBQC** リポジトリから、より広いシステムアーキテクチャ部分を分離したものです。OBQCはそろばん型の光パターン符号化に焦点を置き、このリポジトリは電子制御と光処理をどのように統合するかに焦点を置きます。

## 中核命題

電子計算と光計算は、相互に排他的な道として扱うべきではありません。

次世代の実用的な計算アーキテクチャには、両方が必要になる可能性があります。

```text
電子:
  制御、記憶、順序管理、補正、検証、集積化

光:
  高次元状態表現、並列伝送、パターン処理、
  波長 / 位相 / 偏光 / 時間ビン / 空間符号化

ハイブリッド層:
  校正、復号、フィードバック、誤り監視、安全な制御
```

本構想の仮説は、電子・光ハイブリッドシステムが、古典的な計算から将来的な量子互換フォトニックシステムへ向かう、現実的な橋渡しになりうるというものです。

このリポジトリは、次のものを主張しません。

- 完成済みの量子コンピューター
- 実用的なフォールトトレラント量子アーキテクチャ
- 量子優位性

- 実証済みの商用プロセッサ設計
- 熱力学、量子力学、情報理論の突破

これは、**概念アーキテクチャ**であり、オープンな技術仮説です。性能に関する主張は、シミュレーション、試作測定、再現性、既存の電子計算・光計算・量子計算との比較によって検証される必要があります。

このリポジトリでは、完成済みの「量子コンピューター」ではなく、より安全な表現として **量子互換 / quantum-compatible** を使用します。

- 電子制御

```text
OBQC

```

## アーキテクチャ層

### 1. 電子制御層

電子層は、精度、信頼性、プログラム可能性、フィードバックが必要な処理を担当します。

想定される構成要素：

- CPU / マイクロコントローラ
- FPGA
- ASIC
- CMOS制御回路
- メモリコントローラ
- クロック / タイミング制御
- 安全制御器
- 校正エンジン

主な機能：

- プログラムの順序制御
- メモリアクセス
- 制御フロー
- 誤り確認
- 光状態生成命令
- フィードバック処理
- 監査可能性と再現性

---

### 2. 電子・光インターフェース層

この層は、電子的な命令を光状態へ変換します。

想定される構成要素：

- LEDまたはレーザードライバ
- デジタル・アナログ変換器
- 電気光学変調器
- 位相変調器
- 偏光制御器
- 空間光変調器
- タイミングパルス生成器

主な機能：

- 電子データを光パラメータへ符号化する
- 光量、波長、位相、偏光、時間ビン、空間モードを制御する
- 電子値と光状態の校正関係を維持する

---

### 3. 光処理層

光層は、光の自由度を使って情報を表現、伝送、変換、比較します。

利用しうる自由度：

- 波長 / 色
- 偏光
- 位相
- 時間ビン
- パルス幅
- 強度
- 空間モード
- 経路符号化
- 軌道角運動量
- 周波数ビン構造

想定される機能：

- 高帯域インターコネクト
- パターン表現
- 並列比較
- 多値シンボル符号化
- 行列的な光変換
- 将来的な光量子状態処理

---

### 4. 検出・読み出し層

検出層は、光状態を電子データへ戻します。

想定される構成要素：

- CMOSセンサー
- カラーセンサー
- フォトダイオードアレイ
- アバランシェフォトダイオード
- 長期的な量子拡張用の単一光子検出器
- 分光器
- 干渉計型検出器
- 時間分解検出器

主な機能：

- 光状態の測定
- 強度、位相、時間、スペクトル、空間データの抽出
- 電子的な読み出し信号の生成
- 信頼度指標とノイズ推定の提供

---

### 5. 電子補正・検証層

光状態は、ノイズ、ドリフト、クロストーク、温度、振動、校正誤差の影響を受けやすいため、補正層は不可欠です。

主な機能：

- 最近傍復号
- 閾値復号
- 確率的復号
- 冗長性チェック
- 前方誤り訂正
- 反復測定による多数決
- 信頼度スコア
- ドリフト補正
- 信頼度が低い場合の安全な棄却

この層は、光状態が完全に分離できるという非現実的な前提に依存しないために必要です。

これは長期的な研究層です。

同じ電子・光制御アーキテクチャを、次のような領域へ拡張できるかを検討します。

- 軌道角運動量状態
- 光量子ゲート
- 測定型フォトニック計算

この層は、近未来の決定論的プロトタイプに必須ではありません。即時の量子計算能力を主張するものではなく、将来的な互換方向として含めています。

## 概念的な数理モデル

単純化したハイブリッドシステムは、次のように表せます。

```text
H = (E, I, O, D, C, Q)
```

各要素は次を意味します。

- `E` = 電子制御・記憶層
- `I` = 電子・光インターフェース層
- `O` = 光状態処理層
- `D` = 検出・読み出し層
- `C` = 補正・校正・検証層
- `Q` = 任意の量子互換拡張層

決定論的な光状態は、次のように表せます。

```text
S_o = (lambda, P, phi, tau, w, s, l, A)
```

各要素は次を意味します。

- `lambda` = 波長 / 周波数
- `P` = 偏光
- `phi` = 位相
- `tau` = 時間ビン
- `w` = パルス幅
- `s` = 空間モードまたは位置
- `l` = 軌道角運動量
- `A` = 振幅または強度

実用的な復号器は、次を推定する必要があります。

```text
S_hat = decode(measure(S_o + noise + drift + crosstalk))
```

堅牢なシステムでは、単に `S_hat` を出力するだけでなく、次も必要になります。

```text
confidence(S_hat)
margin(S_hat)
error_risk(S_hat)
reject_if_uncertain(S_hat)
```

## 検証可能な仮説

このリポジトリは、完成済みハードウェアの主張ではなく、検証可能な仮説を中心に構成します。

### 仮説1：ハイブリッド制御は光処理の実用性を高める可能性がある

電子制御、校正、補正を加えることで、純粋な光のみのシステムよりも、多値光処理を実用化しやすくなる可能性があります。

検証方法：

- 電子補正あり / なしで光復号精度を比較する
- ノイズ、ドリフト、クロストーク下での堅牢性を測定する

---

### 仮説2：光状態表現は通信ボトルネックを減らす可能性がある

状態転送、パターン比較、並列読み出しが重要なタスクでは、高次元の光表現が有利に働く可能性があります。

検証方法：

- 帯域幅、1シンボルあたりエネルギー、エラー率、遅延を、二値電子方式または二値光方式と比較する

---

### 仮説3：量子互換設計は将来の再設計コストを下げる可能性がある

最初から光量子制約を意識して電子・光インターフェースを設計すれば、将来的にqudit型または光量子システムへ移行する際の再設計コストを下げられる可能性があります。

検証方法：

- 古典光状態から光量子状態へ移行しても有用なインターフェース要素を特定する
- 損失、位相安定性、タイミングジッター、検出器ノイズ、校正互換性を測定する

## 試作ロードマップ

### Phase 0：概念アーキテクチャ

- システム層を定義する
- 決定論的な光計算と量子互換拡張を分離する
- 必要なインターフェースと故障モードを特定する
- 主張しないことを明記する

### Phase 1：古典的電子・光シミュレーター

- 電子制御と光状態生成をシミュレーションする
- ノイズ、ドリフト、クロストーク、量子化、センサー限界を追加する
- 信頼度スコア付きで復号する
- 二値ベースラインモデルと比較する

### Phase 2：RGBW / CMOS光プロトタイプ

- RGBまたはRGBW LEDを使う
- CMOSまたはカラーセンサーで読み出す
- 小規模な状態アルファベットを符号化する
- 最近傍復号、棄却閾値、校正ドリフトをテストする

### Phase 3：多自由度光プロトタイプ

- 波長、偏光、時間ビン、空間状態符号化を組み合わせる
- 電子校正と補正を加える
- 環境変動下で多値復号をテストする

### Phase 4：量子互換ラボ拡張

- 単一光子源または減衰コヒーレント光を評価する
- 時間ビン、周波数ビン、経路、偏光の量子互換符号化をテストする
- 損失、コヒーレンス安定性、検出器要件、ノイズ感度を測定する

### Phase 5：研究段階の光量子拡張

- qudit互換ゲートまたは測定型フォトニックアーキテクチャを検討する
- 既存の光量子コンピューティング手法と比較する
- この段階には専門家との共同研究と実験室検証が必要です
